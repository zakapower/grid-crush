## Шаги в RuStore Консоли

1. Зарегистрируйся / войди: https://console.rustore.ru/
2. Роль **Владелец** компании → **Приложения** → **Добавить приложение** → название `Grid Crush`
3. Тип: **Универсальный** (телефон) — ТВ можно не заполнять, если не целишься на ТВ
4. **Загрузить версию** → APK `GridCrush-v1.0.0-release.apk`
5. Заполни карточку (тексты из `listing.txt`)
6. Загрузи иконку `media/icon-512.png`
7. Загрузи **не меньше 3** вертикальных скриншотов телефона
8. Контакт разработчика: укажи **email** (обязателен хотя бы один контакт)
9. Безопасность данных: приложение **не собирает** персональные данные, всё локально; разрешение только вибрации
10. Отправь на модерацию

Официальная инструкция: https://www.rustore.ru/help/developers/publishing-and-verifying-apps/app-publication

## Важно

- После публикации **не меняй** `applicationId` (`com.zaka.gridcrush`)
- Каждое обновление: увеличь `versionCode` (2, 3, …) и обнови `versionName` (1.0.1, 1.1.0, …)
- Храни `keystore.properties` и `.jks` в безопасном месте (бэкап)
- Если скриншотов нет — сделай 3–5 снимков на телефоне (меню, игра, пауза, конец партии, настройки)
